GS-QRHub
Documentation

A single-endpoint API for generating QR codes and barcodes as SVG. 11 QR types, 10 barcode formats, fully customisable output. No authentication required.

Overview

GS-QRHub exposes one generation endpoint: GET /. The type query parameter selects what to generate; additional parameters provide the content. The response is always a raw image/svg+xml string on success, or a JSON error object on failure.

qr
Plain text or any URL
wifi
WiFi network credentials
vcard
Contact card (vCard 3.0)
email
Email compose link
sms
SMS to a phone number
phone
Phone call dial link

Geographic coordinates
whatsapp
WhatsApp deep link
event
Calendar event (iCal)
crypto
Cryptocurrency payment
otp
TOTP authenticator
barcode
10 barcode formats

Base URL

All requests are GET to the root path. Replace the host with your deployment URL.

Base
https://your-deployment.onrender.com/

The interactive generator lives at /ui and this documentation at /docs.

Quickstart

Generate your first QR code in one request:

curl
curl -s "https://your-host/?type=qr&url=https://example.com" -o qr.svg
JavaScript (fetch)
const res = await fetch('/?type=qr&url=https://example.com');
const svg = await res.text();
document.getElementById('qr').innerHTML = svg;
Python (requests)
import requests
r = requests.get("https://your-host/", params={"type": "qr", "url": "https://example.com"})
open("qr.svg", "w").write(r.text)

Success

HTTP 200
Content-Type: image/svg+xml

Error

HTTP 4xx / 5xx
Content-Type: application/json

{
  "success": false,
  "error": "Validation message"
}

ℹ️
Stack traces are never exposed in production. All errors return clean JSON.

QR Types

qr — Plain Text / URL

The simplest type. Encode any string or URL into a QR code. Use url for links and text for everything else.

ParamRequiredDescription
type=qrreqType selector
textopt*Any string to encode. Required if url is absent.
urlopt*A valid http:// or https:// URL. Required if text is absent.
Examples
/?type=qr&text=Hello World
/?type=qr&url=https://geetasystems.in
/?type=qr&url=https://example.com&size=500&errorCorrectionLevel=H

wifi — WiFi Network

Generates a WiFi QR code using the WIFI: URI scheme. Scanning with a phone instantly connects to the network — no typing required.

ParamRequiredDescription
ssidreqNetwork name (SSID)
passwordoptNetwork password. Required for WPA/WEP; omit for nopass.
securityoptWPA (default), WEP, or nopass
hiddenopttrue if the network is hidden. Default: false
Examples
/?type=wifi&ssid=OfficeWifi&password=secret123&security=WPA
/?type=wifi&ssid=GuestNet&security=nopass
/?type=wifi&ssid=HiddenNet&password=pass&security=WPA&hidden=true

vcard — Contact Card

Generates a vCard 3.0 QR code. Scanning adds the contact directly to the phone's address book.

ParamRequiredDescription
namereqFull name (FN field)
phoneoptPhone number
emailoptEmail address (must be valid)
orgoptOrganisation name
titleoptJob title
urloptWebsite URL
addressoptStreet address
Example
/?type=vcard&name=Harsh Yadav&phone=+919876543210&email=harsh@geetasystems.in&org=Geeta Systems&title=Founder

email — Email Compose

Opens the device's mail client with pre-filled recipient, subject, and body fields.

ParamRequiredDescription
toreqRecipient email address (validated)
subjectoptEmail subject line
bodyoptEmail body text
Example
/?type=email&to=harsh@geetasystems.in&subject=Hello&body=Great to meet you!

sms — SMS Message

Opens the device's SMS app with a pre-addressed, pre-filled message.

ParamRequiredDescription
phonereqPhone number (7–15 digits, optional + prefix)
messageoptPre-filled SMS body
Example
/?type=sms&phone=9876543210&message=Hi there!

phone — Phone Call

Generates a tel: URI. Scanning dials the number immediately on most phones.

ParamRequiredDescription
numberreqPhone number including country code
Example
/?type=phone&number=+919876543210

geo — Geographic Location

Generates a geo: URI. Scanning opens the device's map app at the specified coordinates.

ParamRequiredDescription
latreqLatitude — must be −90 to 90
lngreqLongitude — must be −180 to 180
Example — Aligarh, UP
/?type=geo&lat=27.8974&lng=78.0880

whatsapp — WhatsApp

Generates a wa.me deep link. Scanning opens a WhatsApp chat with the specified number and optional pre-filled text.

⚠️
The phone param must be in international format without the + sign. E.g. 919876543210 not +919876543210.
ParamRequiredDescription
phonereqInternational number without + (e.g. 919876543210)
messageoptPre-filled message text
Example
/?type=whatsapp&phone=919876543210&message=Hello from GS-QRHub!

event — Calendar Event

Generates an iCalendar (VEVENT) QR code. Scanning imports the event into the device's calendar app.

ParamRequiredDescription
titlereqEvent title (SUMMARY field)
startreqStart datetime — ISO 8601 format (e.g. 2026-06-01T10:00:00Z)
endoptEnd datetime — ISO 8601 format
locationoptVenue or address
descriptionoptEvent notes
Example
/?type=event&title=React Aligarh Meetup&start=2026-07-15T10:00:00Z&end=2026-07-15T13:00:00Z&location=Aligarh

crypto — Cryptocurrency Payment

Generates a BIP-21 compatible payment URI. Scanning opens the corresponding wallet app to initiate a payment.

ParamRequiredDescription
coinreqCoin identifier (e.g. bitcoin, ethereum, litecoin)
addressreqWallet address
amountoptPayment amount in the coin's base unit
labeloptHuman-readable label for the payment
messageoptA note attached to the payment request
Example
/?type=crypto&coin=bitcoin&address=1A1zP1eP5QGefi2DMPTfTL5SLmv7Divf&amount=0.001&label=Invoice%20001

otp — TOTP Authenticator

Generates an otpauth://totp/ URI for importing into authenticator apps like Google Authenticator, Authy, or 1Password.

🔐
The secret must be a valid Base32-encoded string (characters A–Z and 2–7). Padding characters (=) are allowed.
ParamRequiredDescription
issuerreqApp or service name shown in the authenticator
accountreqUser identifier (usually email)
secretreqBase32-encoded TOTP secret
algorithmoptSHA1 (default) or SHA256
digitsopt6 (default) or 8
periodoptToken validity in seconds. Default: 30
Example
/?type=otp&issuer=BtoE&account=user@btoe.in&secret=JBSWY3DPEHPK3PXP

Barcode Formats

All barcode requests use type=barcode. The format parameter selects the barcode symbology.

ParamRequiredDescription
textreqThe data to encode. Must match the format's character set.
formatoptBarcode symbology. Default: code128
includetextoptSet to false to hide the human-readable text below the barcode. Default: true

Supported Formats

code128 code39 ean13 ean8 upca upce interleaved2of5 gs1-128 pdf417 datamatrix
FormatUse CaseCharacter Set
code128General-purpose; shipping, logisticsFull ASCII
code39Industrial, automotive, ID cardsA–Z, 0–9, some symbols
ean13Retail product barcodesExactly 13 digits
ean8Small retail packagesExactly 8 digits
upcaUS retail (UPC)Exactly 12 digits
upceCompressed UPC for small items6 digits (compressed)
interleaved2of5Numeric-only logisticsEven number of digits
gs1-128Supply chain / GS1 standardFull ASCII with AI codes
pdf417High-density 2D stacked barcodeFull ASCII (large payload)
datamatrixTiny 2D matrix, electronics/pharmaFull ASCII
Examples
/?type=barcode&text=ABC123&format=code128
/?type=barcode&text=012345678905&format=ean13
/?type=barcode&text=HELLO WORLD&format=code39
/?type=barcode&text=12345678&format=ean8
/?type=barcode&text=Invoice-001&format=pdf417&size=500
/?type=barcode&text=GS1DATA&format=datamatrix&includetext=false

Render Options

These parameters apply to all types and control the visual output of the generated SVG.

ParamDefaultRangeDescription
size30050–2000Output width in pixels
margin40–20Quiet zone modules around the code
darkColor000000HexModule (dark) color — hex without #
lightColorffffffHexBackground (light) color — hex without #
errorCorrectionLevelML M Q HQR error correction level (QR types only)

Color Examples

Color customisation
# Dark on white (default)
/?type=qr&text=Hello&darkColor=000000&lightColor=ffffff

# White on dark (inverted) — scan may not work on all readers
/?type=qr&text=Hello&darkColor=ffffff&lightColor=1a1a2e

# Brand green on cream
/?type=qr&url=https://geetasystems.in&darkColor=1a6b4a&lightColor=f7f6f2

# Large, high-reliability QR for print
/?type=qr&url=https://example.com&size=800&errorCorrectionLevel=H&margin=8

Error Correction Levels (QR only)

LevelRecoveryWhen to use
L~7%Clean digital displays with no damage risk
M~15%Default — good balance for most uses
Q~25%Print materials that may get slightly damaged
H~30%High wear environments; allows logo overlay

Rate Limiting

The API applies a sliding-window rate limit per IP address. The default is 100 requests per minute, configurable via the RATE_LIMIT environment variable.

HeaderDescription
RateLimit-LimitMaximum requests allowed in the window
RateLimit-RemainingRequests remaining in the current window
RateLimit-ResetSeconds until the window resets

When exceeded, the API responds with HTTP 429:

HTTP 429
{
  "success": false,
  "error":   "Rate limit exceeded. Max 100 requests per minute."
}
